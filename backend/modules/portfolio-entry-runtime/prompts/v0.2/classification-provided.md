Skill 01 Intent Detection (provided).

The classification of this turn (initial_entry_state, current_frame, primary_intent, secondary_intents) is decided outside of you and arrives in the `classification` field of the input. Treat it as fixed and do not return those fields.

Use it to guide extraction, reverse alignment and questions. When a value is `unknown`, the input did not support a classification: plan a clarifying question instead of guessing.
